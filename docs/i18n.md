# Internationalization

Talabix supports English (`en`) and Arabic (`ar`) across the shared contract package, portal web, customer app, rider app, and Laravel-generated messages.

## Locale Strategy

- English is the fallback locale.
- Arabic is RTL; English is LTR.
- API wire values, database enum values, permission names, token abilities, UUIDs, route paths, and channel names stay untranslated.
- User-facing labels for enum values must be read through `labelForEnum()` instead of rendering raw wire values.
- Dynamic business data such as merchant names, branch names, customer names, SKU values, and addresses are displayed as stored.

## Shared JS Pattern

- Put frontend/mobile text in `packages/shared/src/i18n/index.js`.
- Use namespace keys by feature, for example `customer.home.discoveryTitle` or `ops.dashboard.grossSales`.
- Use `{name}` interpolation, not string concatenation, for translated sentences.
- Use `tp()` for count-based labels where singular/plural wording changes.
- Use `formatCurrency()`, `formatDate()`, `formatDateTime()`, `formatNumber()`, and enum label helpers from the active app i18n context.
- Do not add visible strings directly inside JSX, React Native `Text`, placeholders, labels, aria labels, alerts, or feedback messages.

## RTL Rules

- Portal web sets `document.documentElement.lang` and `document.documentElement.dir` from `I18nProvider`.
- Mobile UI components apply `writingDirection` and logical text alignment from the active locale.
- Prefer CSS logical properties and `text-align: start` over hardcoded left/right.
- Direction-specific fixes belong in shared layout components or `[dir='rtl']` CSS rules, not one-off screen hacks.

## Backend Pattern

- Laravel resolves locale from `X-Talabix-Locale`, `X-Locale`, then `Accept-Language`.
- Backend user-facing messages live under `apps/api/lang/{en,ar}`.
- Validation responses use the localized `messages.validation.failed` envelope while preserving the Laravel `errors` object.
- Notifications and mail content use translation files; stored notification title/body values are localized at queue time.

## Safeguard

Run this before committing UI work:

```bash
npm run i18n:audit
```

The audit fails when strict i18n files contain literal user-facing text. New UI files must add `i18n-audit: strict` before merge. If a string is technical and intentionally not translated, add a narrow `i18n-audit: ignore-line` comment with the reason in the same code review.
